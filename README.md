# 🏃‍♂️ 원 스텝 천 리 (One Step Thousand Li)

> 거대한 목표를 작고 실행 가능한 단위로 쪼개고, 꾸준한 집중을 통해 달성하도록 돕는 일정 관리 웹 애플리케이션입니다.

## 📝 프로젝트 소개
'원 스텝 천 리'는 막연하고 큰 목표 앞에서 느끼는 부담감을 줄여주기 위해 기획되었습니다. 목표를 체크리스트 형식으로 분할하고, 뽀모도로 타이머를 활용해 집중력을 극대화할 수 있는 환경을 제공합니다. 또한, 학습 통계와 친구들과의 경쟁을 통해 지속적인 동기부여를 얻을 수 있습니다.

## ✨ 주요 기능
- **과제 추가:** 크고 복잡한 목표를 직관적이고 작은 단위의 체크리스트로 세분화하여 관리합니다.
- **뽀모도로 타이머:** 작업에 온전히 몰입할 수 있도록 시간 관리 타이머를 제공합니다.
- **통계 및 데일리 리포트:** 매일의 목표 달성률과 집중 시간을 데이터로 시각화하여 개인의 성장을 추적하고, 알림을 받습니다.
- **친구와의 경쟁:** 친구를 맺고 서로의 진행 상황을 공유하거나 순위 제도를 이용해 각자의 달성률을 확인합니다.

## 🛠 기술 스택

### Backend
- **Framework:** Spring Boot (Java 17)
- **ORM:** Spring Data JPA
- **Build Tool:** Gradle

### Database
- **RDBMS:** MariaDB

### Infrastructure & Deployment
- **Hosting:** Cloudtype (클라우드타입)
- **Architecture:** - Spring Boot Application 서버 상시 가동
